# 流体（`fluid` 包）

相关：[思维流体方块的实现](../block/README.md) ・ [灵感充能（只存在于机器里的流体）](../machine/charge/README.md)

思维流体桶由水桶 + 末影之眼 + 灵感无序合成。把思维流体倒出来，只要它接触到水或岩浆就会凝固，
产物取决于「接触的流体」与「思维流体是源还是流动」：

| 接触 | 源 | 流动 |
| --- | --- | --- |
| 水 | 浓缩灵感结晶 | 稀释灵感结晶 |
| 岩浆 | 思维水晶岩 | 灵感凝胶 |

| 方块 | 外观 | 挖掘 | 掉落 |
| --- | --- | --- | --- |
| 稀释灵感结晶 | 半透明淡绿晶体 | 石镐 | 灵感碎片 ×2，受时运加成 |
| 浓缩灵感结晶 | 几乎不透明的深绿晶体 | 铁镐 | 灵感 ×1，受时运加成 |
| 思维水晶岩 | 嵌紫色晶簇的深色岩石 | 铁镐 | 思维晶体 ×1 |
| 灵感凝胶 | 半透明凝胶 | 徒手 | 自身 |

四种方块都带精准采集掉落自身的掉落表。反应只替换思维流体所在的那一格，水与岩浆不受影响，
所以可以反复往同一处浇液体稳定量产结晶。

- 灵感碎片可以放进机器的充能槽，每片提供 100 mB 灵感充能（写在物品描述里）。
- 思维晶体与灵感凝胶目前没有进一步用途，作储备材料。
- 灵感凝胶继承原版粘液块：可弹跳、免疫摔落伤害、踩上去减速。

## 实现

反应判定放在 `MindFluidBlock`，`MindFluidReactions` 只是规则表。

没用 NeoForge 的 `FluidInteractionRegistry`，是因为它沿用原版 `LiquidBlock#shouldSpreadLiquid`
的方向表（正上方 + 四个水平方向），漏掉了「思维流体正好落在一格水上」这种正下方相邻的情况，
那会变成思维流体顶掉水而不是结晶。这里改为接管方块的放置与邻居更新两个时机，
遍历 `Direction.values()` 六个方向一并检查。

注意：子类化原版方块时 codec 泛型是不变型的——`SlimeBlock#codec()` 返回 `MapCodec<SlimeBlock>`，
子类不能收窄，灵感凝胶不能照抄一半。

流体方块本身用 `registerBlockOnly` 注册（**不注册物品**）：注册了物品却缺
`models/item/*.json`，物品栏里就是黑紫块。
