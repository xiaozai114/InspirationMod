# 辐射机制

相关：[方块登记点](../block/README.md) ・ [数据生成](../recipe/README.md)。独立于维度的区块级污染系统：
任何物品 / 方块登记一个数值就会参与结算。

| 量 | 含义 | 存放 |
| --- | --- | --- |
| 辐射值 | 单个物品 / 方块的属性，「每秒注入多少点」 | `inspiration:radiation` 数据地图 |
| 辐射周期 | 「每 N 秒释放一次」 | `inspiration:radiation_denominator` |
| 区块辐射 | 区块当前累积值 | 每维度一份 `SavedData` |
| 玩家辐射 | 玩家体内累积值 | 玩家 attachment |

## 结算

**每秒**

- **方块**：值 x 的方块只要六面中**任意一面接触空气**就注入 x；被完全包住（埋着的矿）不注入 ——
  这正是「钫盐矿不露天生成」的前提。
- **物品**：背包里（含装备栏与副手）注入 **x × 件数**。九件压成方块时块值是单件的 9 倍，
  按件数计才对得上；方块物品（矿 / 盐块 / 钫块）也走这条。
- **玩家**：站在辐射区块里，每秒吸收一次该区块的当前值。

**分数辐射（分子 + 周期）**：粒（1/9 锭）与尘（1/81 锭）没法用整数表示，所以拆两张表 ——
`radiation` 写分子（粒沿用锭的数，如铀粒 2），`radiation_denominator` 写周期（锭不写 = 1、
粒 9、尘 81）。判定 `秒数 % 周期 == 0`，语义是「**每 N 秒释放 M 点**」，于是 9 枚铀粒在 9 秒里
的总量与 1 枚铀锭相同（平均速率一致，结算更稀疏）。
⚠️ **RTG 只收周期为 1 的燃料**，否则一粒会被当成一锭满功率烧。

**每小时（72000 刻 = 3600 秒）**，设区块值为 x：

- 向四个正方向中**值严格更低**的邻区块各传播 `⌊x/100⌋`，额外自发衰减 `⌊x/10⌋`，
  且**传播出去的份额从源扣除**（是传播不是复制）；
- 玩家衰减 `⌊x/10⌋`，并把另外 `⌊x/10⌋` 倒回所在区块 —— 每小时掉 `2⌊x/10⌋`，一半进脚下区块。

三条口径（不符预期就改这里）：只向四个正方向（不含斜角）、传播从源扣、物品按件数累计。

**玩家中毒**：每层完全包含上一层，按阈值从低到高覆盖（效果 3 秒、每秒刷新，离开自然消退）：

| 阈值 | 表现 |
| --- | --- |
| > 10K | 虚弱 I、饥饿 I |
| > 50K | 虚弱 II、挖掘疲劳 I |
| > 100K | 挖掘疲劳 II；**治疗被换算**（该回的血按 1:10 变成辐射衰减） |
| > 500K | 缓慢 I、失明 |
| > 1M | 凋零 I、饥饿 II、缓慢 II、挖掘疲劳 III、虚弱 III |

死亡后体内辐射减半（非死亡的克隆原样搬运）。

## 辐射吸收器与防护

辐射吸收器的工作台配方为 5 无恒合金、3 铀锭和 1 高能核心。它只在本区块有污染且供电充足时运行，每刻用 400 FE，累计 1,200 个工作刻清除 1 点。每台独立累计，实际清除 64 点产出 1 个核废料。缺电、区块清零或第 64 点的废料没有输出空间时暂停。两条进度条分别显示本分钟和本批废料的进度，随区块存档。

每件注能翡翠钢盔甲增加 1 点韧性，穿在对应部位时减少 20% 新增体内辐射，全套减少 80%。不足一点的剂量会累计，玩家存档和跨维度时保留。

注能金苹果清除 1,000 点体内辐射并提供 5 分钟辐射抵抗，注能附魔金苹果清除 10,000 点并提供 30 分钟保护。两种苹果均保留原版食物效果。辐射抵抗期间仍会吸收环境辐射，可以正常回血，饮用药水或生物攻击造成的负面效果继续计时。

## 辐射源（钫盐系列）

流程与铯盐完全对应，只是全流程带辐射：

| 物品 / 方块 | 值 |
| --- | --- |
| 钫盐矿、粗钫盐、钫盐 | 1 |
| 钫粉、钫锭 | 3 |
| 钫盐块（9 钫盐） | 9 |
| 钫块（9 钫锭） | 27 |

三个**方块物品**在物品表里也各登记一份同样的值，所以放在地上（方块表）和拿在身上（物品表）
都参与结算；两张同名表分属两个注册表，在 `data/inspiration/data_maps/{item,block}/radiation.json`。
钫盐矿只在**地狱 Y 95~124** 稀有生成，`discard_chance_on_air_exposure = 1.0`（露天不生成），
矿脉底色是地狱岩。钫的碱性略强于铯，`AlkaliItem` 爆炸半径取 **6f**（铯 4f）。

## 实现要点

- **数值走数据地图**并加了 `.synced(...)` —— 客户端要靠它画 tooltip。
- **不能每刻全图扫描**：`RadiationBlockTracker` 只在区块加载时排队，每刻最多 2 个；
  扫之前先查区块段的**调色板**，没出现过登记过的方块直接跳过。
- **传播要双缓冲**：`tickHourly()` 先在快照上算完所有增减再统一写回，否则结算次序会影响结果。
- 辐射病施加的状态用 NeoForge 的自定义 `EffectCure` 标记。同名药水或生物效果可在隐藏层继续计时，开始辐射抵抗时恢复有效的其他来源。
- **attachment 默认不随死亡拷贝**，`RadiationEvents#onClone` 显式搬运并做死亡减半。
- 常量：20 刻/秒、72000 刻/小时、每刻扫 2 个区块。

## 验证

- `RadiationSavedData#get(level)` 直接读区块值，`#tickHourly()` 手动推一小时（不必等 3600 秒）；
- `RadiationBlockTracker#trackedCount()` / `pendingCount()` / `snapshot()` 核对索引；
- 盖革计数器本身就是给玩家的验证工具：右键在 action bar 打出「区块 x ・ 体内 y（中毒程度）」。
