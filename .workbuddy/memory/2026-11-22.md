## 虚空能量体系：第一阶段（团簇与供能）

用户一次性给了一整条产线（钻头 → 开裂基岩 → 提取器 → 团簇 → 虚空注入 → 凝聚器 → 零点发电机）。
量级很大，先按 4 个问题把底层定死，再分阶段实现。

### 已确定的四个底层决策

| 问题 | 结论 |
| --- | --- |
| 128 GFE 超出 int | 发电机用 **long** 自建能量缓冲，自己画能量条；对外仍给 int 接口 |
| 团簇的载体 | **实体**（无碰撞、发光面片、右键查询） |
| 虚空注入枪 | **新方块**，放进现有注入结构里替换普通注入枪 |
| 64 个增幅器 | **单槽、按 64 堆叠** |
| 10% 扣量 | `cost = max(1, ve/10)`，拿 **cost** 比 [min,max] |
| 中继器 | 必须与团簇**同格**，以自身为中心 ±2（5×5×5） |
| 团簇消失 | 能量归零后持续 200 刻消散 |

### 液态无恒合金（替代先前的偏差）

- `molten(true)` 之所以禁用：`InspirationMaterial#register()` 里 `if (withMolten) throw`。
  一条熔融金属要配四样东西 —— FluidType、源/流、桶、客户端贴图（外加提取机配方），
  当初一期只做了等离子这一条手写实现，所以开关留着禁用（打开会抛异常，避免「开关是空的」）。
- 这次照液态等离子的做法补了无恒合金：`MoltenEphemeralAlloy` + `MoltenEphemeralAlloyFluidType`
  + `FluidType`/源/流注册 + 桶物品 + `MoltenEphemeralAlloyClientExtensions` + 两张贴图（由等离子贴图染紫）。
- 配方：流体提取「无恒合金锭 → 144 mB」；增幅器装配改用 576 mB 该流体。
- 开关本身**仍然禁用**：要通用生成还得把「贴图（一张共享纹理 + FluidType 染色）、桶物品、提取配方」
  都做成数据驱动，属于下一轮的事。

自检：流体/类型/桶都注册为 `inspiration:molten_ephemeral_alloy`，
提取配方与增幅器装配配方均存在（流体的 `getResultItem` 自然是 air）。
