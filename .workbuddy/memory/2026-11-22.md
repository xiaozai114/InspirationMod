# 2026-11-22

## 虚空能量体系：第一阶段（团簇与供能）

用户一次性给了一整条产线（钻头 → 开裂基岩 → 提取器 → 团簇 → 虚空注入 → 凝聚器 → 零点发电机）。
量级很大，先按 4 个问题把底层定死，再分阶段实现。

### 已确定的四个底层决策

| 问题 | 结论 |
| --- | --- |
| 128 GFE 超出 int | 发电机用 **long** 自建能量缓冲，自己画能量条；对外仍给 int 接口 |
| 团簇的载体 | **实体**（无碰撞、发光面片、右键查询） |
| 虚空注入枪 | **新方块**，放进现有注入结构里替换普通注入枪 |
| 64 个增幅器 | **单槽、按 64 堆叠** |
| 10% 扣量 | `cost = max(1, ve/10)`，拿 **cost** 比 [min,max] |
| 中继器 | 必须与团簇**同格**，以自身为中心 ±2（5×5×5） |
| 团簇消失 | 能量归零后持续 200 刻消散 |

### 虚空注入的口径修正（用户拍板）

- **虚空注入只吃 ve，不吃 FE**：虚空注入枪没有能量缓冲，配方只有 ve 窗口。
- **虚空合金不是虚空注入**：它走普通注入（末地合金 + 虚空露珠，tier 2，FE 窗口 `{1}`），不消耗 ve。
- 做法选方案 1（继承）。为此给 `InjectionGunTile` 开了四个钩子并放宽可见性：
  `startInjection` / `advanceInjection` / `finishInjection` / `succeed` / `overload` /
  `resolveActiveRecipe` 改 `protected`；`activeRecipe`、`activeOutcome`、`remainingTicks`、
  `injectSlot`、`powered`、`activeRecipeId` 改 `protected`；新增
  `hasResolvedRecipe()` / `ensureRecipeResolved()` / `pendingResult()`，
  并且 `finishInjection` 改成吃 `ItemStack`（原来直接读 `InjectionRecipe#result`）。
  改完编译通过、普通注入行为不变。
