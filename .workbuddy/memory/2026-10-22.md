### 两个新踩到的坑

1. **ID 不带 `_ingot` 的材料必须显式 `.itemId(...)`**：默认派生出 `basalt_alloy_ingot`，
   配方 JSON 会**静默**改用新 ID —— 只有清空重生成 + git diff 才看得出来。

   磁盘上还是旧内容 → 假的「零变化」。**核对前必须 `rm -rf src/generated/resources`**。
