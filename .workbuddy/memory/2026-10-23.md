## 新踩到的坑

1. **`sed -i` 会把 CRLF 改成 LF**（本机 `core.autocrlf=true`）。批量替换后 `git status`
   一片 M，但 `git diff --numstat` 是空的。提交前用脚本把 `src/main/java` 下的
   `.java`/`.md` 统一回 CRLF，工作区才干净。
2. **`git reset --soft` 后按路径 `git add` 再 commit，会把索引里**全部**改动一起提交**
   （soft reset 保留了原索引）。要分组提交得用 `--mixed`（默认）重置索引再逐组 add。
3. **移动文件后旧路径的删除也要 stage**：只 add 新路径会漏掉 ` D` 的旧文件，
   中间 commit 里会同时存在新旧两份。
