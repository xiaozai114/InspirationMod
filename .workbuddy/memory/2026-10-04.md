# 2026-10-04

## 注入枪插件槽 + 电容降级插件

- 插件系统重构：`MachinePluginType` 每种插件自带 `multiplier()`（原来是全局 `MULTIPLIER` 常量），
  `PluginEffects` 按各自倍率叠乘；新增 `ENERGY_CAPACITY_DOWNGRADE`（0.67）。
- 抽出两个公共类给「机器」和「注入枪」共用：
  - `machine/plugin/PluginInventory`：创建（非 MachineTile 用）与配置四个插件槽——只收插件、每槽一个、
    `disableFacingAddon()`、所有侧面 `FaceMode.NONE`（照抄 Titanium `MachineTile` 的 augment 槽做法，
    免得被管道偷偷改装）。槽位坐标沿用 Titanium 的 (180, 11)。
  - `machine/plugin/PluginHost`：槽位内容指纹 + 变化时重算 `PluginEffects` 并回调宿主。
    `InspiredMachineTile` 原来的私有指纹逻辑删掉，改成复用它。
- 注入枪：`createEnergyStorage` 换成 `PluginEnergyStorage`，每刻 `plugins.refresh()`，
  只认容量类效果；`initClient` 补画 `AssetTypes.AUGMENT_BACKGROUND` 底板。
- 新插件 `capacitor_downgrade_plugin`：ModItems / 模型 / 创造页 / 中英文 / 装配配方
  （等离子锭 + 铁锭，默认 300 刻、200 FE/t）；贴图由 `gen_plugin_textures.py` 生成（向下的双箭头、暗红）。

## JEI 精简

- 融合 / 重塑 / 扭曲 / 装配四个分类改为只显示两行：`MachineRecipeText.baseLines()`
  → `jei.inspiration.machine.duration`（耗时）+ `jei.inspiration.machine.energy_per_tick`（每刻耗电）。
  删旧的各分类 `duration/energy/cost` 键；装配的流体行保留（目前没配方用到，注释里写了加高背景的前提）。
- 扭曲的产量区间移到输出槽 tooltip（`addRichTooltipCallback`，旧的 `addTooltipCallback` 已过时）。

## 新增坑

- **服务端不能引用客户端类，即使那个方法永远不会被服务端调用**。`InjectionGunTile#initClient`
  里 `new AssetScreenAddon(...)` 导致专用服务器报错
  `Attempted to load class GuiEventListener for invalid dist DEDICATED_SERVER` —— JVM 在链接期就要
  验证所有方法，需要加载返回类型的父类。解法同 Titanium 自己：方法标
  `@OnlyIn(Dist.CLIENT)`（`net.neoforged.api.distmarker`），dist cleaner 会在服务端剥掉它。
