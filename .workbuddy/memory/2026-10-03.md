# 2026-10-03

## 客户端启动崩溃修复（ModEntities 未注册）

现象：客户端 `Initializing game` 阶段抛
`NullPointerException: Trying to access unbound value: ResourceKey[minecraft:entity_type / inspiration:intensified_tnt]`，
发生在 `EntityRenderersEvent$RegisterRenderers`。

根因：`ModEntities.ENTITIES` 这个 `DeferredRegister` **从来没有 `register(modEventBus)`**，
holder 一直未绑定，`get()` 直接 NPE。上一轮给 `ClientModEvents` 补上 `@EventBusSubscriber`
后这个类才第一次真正执行，于是把这个潜伏问题暴露成了崩溃。

修复：`Inspiration` 构造函数里补 `ModEntities.ENTITIES.register(modEventBus);`，
并把 `EMPOWERED_TNT` 也绑上 `TntRenderer`（之前只绑了 `INTENSIFIED_TNT`）。

排查手法：全量比对「声明的 DeferredRegister」与「已 register 的」，确认只有 ModEntities 漏了。

## 顺带修复：流体方块多了个无模型的物品

客户端日志 `Unable to load model: inspiration:item/mind_fluid_block`。
`ModBlocks#registerBlocks` 会给每个方块自动注册 `BlockItem`，但流体方块（`MindFluidBlock`）
既没有物品模型也不该有物品，结果在 JEI 物品列表里是黑紫块。
新增 `registerBlockOnly`（只注册方块、不注册物品），`MIND_FLUID_BLOCK` 改用它。

## JEI 背景「黑紫块」的真正根因：贴图路径少了 `.png`

前一轮把背景挪到 `getBackground()` 只解决了「文字被盖住」，背景本身仍是黑紫块。
「黑紫」正是 MC 缺失贴图（黑 + 紫红棋盘格）的配色。根因是
`JeiLayout#background(name)` 拼出来的是 `textures/gui/jei/injection`，**没有扩展名**；
MC 的纹理管理器按 `assets/<namespace>/<path>` 完整路径找文件，不会自动补 `.png`，
于是永远取不到。JEI 自己的 `DebugRecipeCategory` 用的是 `textures/jei/gui/debug.png`，可作对照。
六个分类共用这一个方法，所以六个背景全都是棋盘格。

## 验证：assets 只能在客户端查

第一次验证我偷懒，用服务端的 `MinecraftServer#getResourceManager()` 去查
`inspiration:textures/gui/jei/*.png`，六个全是「缺失」——**这是假阴性**：
服务端资源管理器只加载 `PackType.SERVER_DATA`，看不到 `assets/`。
改成挂 `FMLClientSetupEvent` 的客户端临时类，用
`Minecraft.getInstance().getResourceManager()` 取流 + `NativeImage.read` 解码，
一次 `runClient` 输出：fusion/reshaping/right_click_block/twisting = 104×54、
assembling = 104×74、injection = 150×100，与 `JeiLayout` 常量完全一致。

## TNT 改用我们自己的实体类型

`PrimedTnt(Level, x, y, z, owner)` 内部是 `this(EntityType.TNT, level)`，类型写死，
所以两个自定义 TNT 生成的实体类型一直是原版 TNT：
注册的渲染器绑了也用不上，存档重载后还会还原成原版类、`explode()` 覆盖失效。
新增基类 `entity/CustomTntEntity` 照抄原版初始化流程、只换类型，并自己存一份 `owner`
覆盖 `getOwner()`（父类除该 getter 外不用这个字段）；两个子类只剩威力与交互方式。

服务端自检结果：
- 直接构造 → `inspiration:intensified_tnt`，引信 80，初速度 (0.01, 0.20, 0.02)
- 点燃强化 TNT 方块 → `inspiration:intensified_tnt`，方块已被移除
- 同样场地炸石头：原版 TNT(4)=1 / 强化(8)=16 / 强能(16)=68，严格递增
